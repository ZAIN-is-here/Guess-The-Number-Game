# Guess The Number Game

A simple Guess The Number Game made with Html, Css, Javascript.

## Features
- random number from 1 to 100
- random number from 1 to custom (You Can Set)
- Count attempts
- Get Wins
- Save Wins
- Reset Wins
- Rotating Wheels

## How to Play
Open `index.html` in browser and start Guessing the Numbers!
